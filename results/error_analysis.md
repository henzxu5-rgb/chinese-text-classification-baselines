# 错误分析

训练完成后，从预测错误的评论中抽取部分样本，对照评论正文、真实星级和模型预测进行检查。主要观察如下。

## 1. 相邻星级本身很难区分

不少错误只相差一星，而且评论中常常同时包含表扬和批评。不同用户对三星、四星或四星、五星的判断标准也可能不同。因此，一部分错误不一定只是模型能力不足，也可能与评分边界模糊有关。

TF-IDF 在验证集上的 4,940 条预测中，有 1,848 条只相差一星，预测与真实值相差不超过一星的比例为 94.98%。

## 2. 评论文字不能完全解释评分

部分评论的文字态度和最终星级并不容易对应。用户可能没有把全部想法写在评论里，也可能存在反讽、误点或其他噪声。因此，不能仅根据文字就断言标签一定错误。

## 3. 模型容易依赖局部片段

TF-IDF 把评论拆成字符片段并分别赋予权重，因此“五分”“推荐”等片段可能产生较强影响，但模型不一定能正确处理它们附近的否定或转折。

TextCNN 能学习 3—5 个字符组成的局部特征，但经过最大池化后同样会损失很多上下文信息。因此，更准确的说法不是“模型真正理解了又理解错了”，而是它利用了局部相关线索，却没有充分整合整句评论。

## 4. 样本 5124

模型分歧样本 `5124` 的大部分内容是粤语，结尾包含“差评！负分！”，真实标签为一星。TF-IDF 预测三星，TextCNN 预测一星。

初步假设是 TextCNN 捕捉到了结尾的负面表达，而 TF-IDF 没有。通过删除结尾、只保留结尾的实验发现，两种模型其实都能利用“差评！负分！”这一片段；它们的差别更可能在于如何把结尾与评论其余部分结合。

该案例说明，不能只根据一个预测结果判断模型能力。个别案例适合提出假设，但要证明一种稳定规律，还需要更多样本和更系统的实验。

## 5. 两个模型的差异

验证集上，两者都答对 2,173 条；只有 TF-IDF 答对 671 条；只有 TextCNN 答对 569 条；两者都答错 1,527 条。

这说明两个模型确实会利用不同的信息，但目前还不能证明简单组合两个模型一定能提高效果。后续可以固定一组代表性错误样本，在加入类别权重或更强文本表示后继续比较。
